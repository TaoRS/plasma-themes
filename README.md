# TaoRS's Plasma Global Themes Repo

This repository contains my Plasma global themes, which I use to test theme synchronization across multiple machines. It might also be used to store dot files in the future. Note that there are no plans for official support or managing pull requests.

Feel free to take a look if you're interested!
